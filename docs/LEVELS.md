# Level data

`assets/levels/campaign.json` is an original Meatgrinder campaign generated by
`tools/generate_campaign.py`. It contains six worlds and thirty compact levels.
No recovered Hills and Rivers Remain topology or assets are used by this file.

Worlds provide an ID, display name, theme, and overview-map position. Levels
provide an ID, name, briefing, owning world, level-map position, prerequisite
IDs, tile layer, nodes, land links, and optional sea links. The first battle in
each world after World 1 requires the previous world's fifth battle. Within a
world, Levels 2 and 3 branch from Level 1, Level 4 requires Level 2, and Level 5
requires Level 4. Level 3 is therefore optional.

Node fields are explicit and readable:

- `kind`: `node`, `producer`, `cannon`, `fort`, `stable`, `port`, or `mine`.
- `owner`: `0` for player, `1` for enemy, and `-1` for neutral.
- `soldiers`: starting garrison.
- `headquarters`: marks the fixed critical producer for a side.
- `target`: gives a cannon its fixed target node ID.

Land `links` are always part of the route graph. A `sea_links` edge is usable by
an army only while both endpoint ports belong to that army's side. Mine shipment
pathfinding is stricter: every node along its land or active sea route must be
friendly.

The generated 20x12 tile patterns are simple presentation data. Node IDs are
local to a level and stay below 100 so the direct fixed-slot breadth-first route
search remains easy to inspect.
